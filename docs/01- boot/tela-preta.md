# Tela Preta (Black Screen)

## Problema

A Tela Preta (Black Screen) ocorre quando o computador é ligado, mas o monitor permanece completamente preto, com ou sem a exibição do cursor do mouse. Diferentemente da Tela Azul (BSOD), normalmente não há um código de erro exibido, o que torna o diagnóstico mais dependente da análise dos sintomas e do comportamento do sistema.

O problema pode ocorrer antes ou após o carregamento do Windows e pode estar relacionado a falhas de hardware, drivers de vídeo, configurações incorretas de inicialização ou arquivos do sistema corrompidos.

---

## Sintomas

O problema pode se manifestar de uma ou mais das seguintes formas:

- Tela completamente preta após ligar o computador.
- Tela preta com cursor do mouse visível.
- O computador aparenta estar ligado (LEDs acesos e ventoinhas funcionando), mas não há imagem.
- A tela fica preta após o login no Windows.
- O problema ocorre após atualização do Windows ou dos drivers de vídeo.
- A tela preta aparece por alguns segundos e retorna ao normal.
